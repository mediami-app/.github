# MediAmi

**A native Mac and iPad app for the media services you run yourself.**

Connect your own Radarr, Sonarr, Lidarr, SABnzbd and Overseerr/Jellyseerr servers and manage them
from one place, with the look and speed of a built-in app. No account, no analytics, no server of ours.

- 💬 Bugs, ideas and questions: [mediami-app/MediAmi](https://github.com/mediami-app/MediAmi)
- 🗺️ What is planned and what is shipping: the roadmap lives there too.

The app's source code is private. MediAmi is an independent app and is not affiliated with the
projects it connects to.
